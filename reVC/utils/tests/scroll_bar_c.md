helper, the single complete sign record, signed stadium event, all 295 mutable
glyph bytes, message literals and the 22-byte mutable time buffer. CScrollBar is
removed. MovingThings.c calls the public C API directly, removing seven former
C++ sign adapters. Script7.cpp publishes to the same canonical C stadium event.

Win32 and 104 on Win64. C++ objects are never reinterpreted as C records.

matrix, vertex and render-state access. Both actual CVector projection objects
stay alive throughout the complete main pixel loop. C addresses their declared
float components and retains its own actual width/height output objects through
projection and sprite callbacks. The optional reflection pass reserves opaque
vertices through the real C shared buffer; only native setters address vertex
storage with the actual D3D9 or GL vertex stride.

four live clock queries, byte promotion before modulo, unsigned character-index
wrap, bitmap shifts and all original random glitches. Initialization retains
the previous intensity. Main rendering has its original lack of a visibility
flag gate, conditional ABS macro, color-cache timing and live bitmap/scale reads.

the original x-only zero-normalizer fallback, strict distance/depth boundaries,
cached color/geometry across reservation flushes, index order and state restore.
